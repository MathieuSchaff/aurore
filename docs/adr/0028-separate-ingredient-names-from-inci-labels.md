# Separate ingredient names from INCI labels

Use one concise French editorial name in ingredient sheets and comparison actives when a
reliable name is available. Keep the INCI name when no suitable French name is established.

## Why

Catalogue names currently mix translations, repeated names and provenance claims. Readers
need an understandable heading and a way to find the ingredient on a product label.

## Decision

1. Keep formula labels as supplied by the product INCI. Formula facts keep those labels too.
2. Use the catalogue name as the primary sheet title and comparison active label.
3. Show the resolved INCI identity separately on the sheet when it differs from the title.
   An absent identity does not justify deriving one from the slug or guessing a translation.
4. Curate names explicitly. Never strip all parentheses or infer provenance from identity.
5. Keep slugs, identities, links, active selection and cosmetic functions unchanged.

## Considered options

- **French primary name, separate INCI:** chosen for readability with a clear label reference.
- **INCI primary name everywhere:** rejected because it makes the explanatory surfaces less
  readable in French.

## Consequences

Editorial name updates also reach catalogue cards and searches. This is a display convention,
not an automatic translation system. The initial catalogue correction covers the reviewed
Cyla/Remedy ingredient sheets; other names require explicit curation. Search must also match
the canonical INCI identity so removing it from a title does not make the sheet harder to find.
